# MakeMeLook — передача в вёрстку

**Дата:** 9 сентября 2026
**Что в архиве:** два макета в виде самостоятельных HTML-файлов, изображения-заглушки, исходные спеки и этот документ.

| Файл | Что это |
|---|---|
| `MakeMeLook Landing.dc.html` | Главная страница, 14 блоков |
| `MakeMeLook Article.dc.html` | Страница статьи журнала (пример) |
| `looks/*.jpg` | Изображения-заглушки, **в продакшн не идут** |
| `support.js` | Рантайм макета: нужен рядом с HTML, чтобы файлы открывались локально |
| `assets/logo-mark.svg` | Знак марки (белый, 34×25) |
| `assets/logo-mark-boxed.svg` | Знак в чёрном квадрате 56×56 |
| `spec/structure.md` | Исходная структура блоков |
| `spec/art-direction.md` | Арт-дирекшн и визуальная система |
| `spec/copy.md` | Тексты |
| `AUDIT.md` | Аудит макета: что закрыто и что осталось |

Файлы открываются в браузере двойным кликом. Разметку и стили можно читать прямо из них: вся вёрстка — обычный HTML с инлайновыми стилями, скрипты только для интерактива.

## 1. Токены

### Цвет

| Роль | Значение | Где |
|---|---|---|
| Ground | `#F2F3F5` | фон страницы |
| Поверхность | `#FFFFFF` | карточки на светлом |
| Поверхность 2 | `#F6F7F9` `#EEF1F5` | вложенные плашки, дорожки ползунков |
| Тёмный ground | `#0E1014` | тёмные секции, футер, шаги |
| Тёмный элемент | `#121417` | кнопки, тёмные карточки внутри светлых секций |
| Чернила | `#121417` | основной текст |
| Чернила 2 | `#3A414B` | текст статьи, вторичный на карточках |
| Вторичный | `#565E6B` | подписи, лиды, служебный текст |
| Приглушённый | `#6B7380` | мелкие подписи, источники (только 11–13px) |
| Сигнал | `#2F5AE6` | акценты, активные состояния, ссылки-действия |
| Сигнал светлый | `#8FB0FF` | акцент на тёмном ground |
| Лёд | `#C9D6E4` `#DDE6F0` `#E4E8ED` | подложки изображений, акцент на тёмном |
| Линия | `rgba(18,20,23,.08)` / на тёмном `rgba(255,255,255,.1)` | разделители |

Правило: **сигнальный цвет — только там, где что-то измерено или требует действия.** В декоре его нет.
На тёмном ground акцентный текст — `#8FB0FF` или `#C9D6E4`, не `#2F5AE6` (не проходит по контрасту).

### Типографика

Шрифты подключаются с Google Fonts:

```
Unbounded 400,500 · Golos Text 400,500,600 · Martian Mono 300,400,500 · Cormorant Garamond italic 400
```

| Уровень | Кегль | Шрифт |
|---|---|---|
| H1 | `clamp(30px, 4vw, 68px)` / 1.02–1.04, tracking −.035em | Unbounded 500 |
| H2 блока | `clamp(28px, 3vw, 44px)` / 1.08, −.03em | Unbounded 500 |
| H3 карточки | `clamp(22px, 2.2vw, 32px)` / 1.1–1.14 | Unbounded 500 |
| Заголовок внутри карточки | 20–22px / 1.28, −.015em | Golos Text 500 |
| Body | 17px / 1.55–1.65 | Golos Text 400 |
| Мелкий | 15px / 1.5 | Golos Text 400 |
| Метка, число, служебное | 11–12px, uppercase, tracking .04em | Martian Mono 400 |
| Крупное число | 20–60px, weight 300, tracking −.02…−.035em | Martian Mono 300 |
| Курсивный акцент в заголовке | `1.15em` от кегля заголовка | Cormorant Garamond italic 400 |

Правила: **все числа — Martian Mono.** Заголовки никогда не капсом; капс только в моно-метках. Курсивный акцент — максимум четыре раза на страницу (H1, «мост», финальный призыв, один заголовок блока).

### Форма и ритм

- **Радиусы: три значения.** `28px` — секционные карточки и крупные плитки. `16px` — вложенные элементы. `999px` — кнопки, метки, пилюли, мелкие элементы ≤28px. Круг `50%` — только точки и аватары.
- **Ни одной тени** на светлом ground. Разделение — волосяной линией. Единственное исключение: `box-shadow: 0 -18px 40px rgba(10,14,22,.18)` на стопке шагов, чтобы фреймы читались как наложенные.
- **Ритм секций:** `200px` сверху перед новой главой (угадайка, калькулятор, продукт, альтернативы, журнал, финальный призыв), `120px` внутри главы. Поля страницы `24px`, у полноэкранных карточек `12px`.
- **Максимальная ширина контента** `1288px`, колонка текста в статье `680px`.
- Сетки — `repeat(auto-fit, minmax(Xpx, 1fr))`, кроме угадайки: там жёстко 4 колонки, до 1000px — 2.

## 3. Что нужно сделать на вёрстке

**Обязательное, без этого не публикуем.** Список из `AUDIT.md`, раздел A:

1. **Реальные изображения.** Всё, что в `looks/`, — заглушки (сгенерированные кадры мудборда). Нужна своя съёмка: один человек, одна поза, меняется только одежда. Для угадайки — восемь уникальных кадров, четыре съёмки и четыре примерки, без повторов и без артефактов.
2. **Видео первого экрана.** 4:5 или 16:9 на всю карточку, петля 6–9 секунд, без звука, `autoplay muted playsinline loop` + постер. Сейчас на его месте `img`.
3. **Ссылки.** Политика обработки данных, типовое согласие, условия, документация — сейчас `href="#"`. Блок 10 обещает документы, которых нет.
4. **Цена.** Блок с пакетами удалён по решению заказчика, но FAQ и блок альтернатив ссылаются на прозрачную цену — согласовать: вернуть короткий ценовой блок или вычистить эти утверждения.
5. **Липкая шапка после первого экрана и липкая кнопка на телефоне.** В макете шапка живёт внутри геро-карточки; дальше по странице кнопки в поле зрения нет.
6. **Формы.** Две формы (заявка, подписка) сейчас только со состоянием «успех». Нужны валидация, состояние отправки, ошибка, отправка на бэкенд и уведомление в тот же день.
7. **Мета-слой.** `title`, `description`, OG-картинка, favicon, canonical.
8. **Аналитика.** Точки замера: открытие карточек угадайки и число ставок, движение ползунков калькулятора, переключение слоёв и табов, отправка форм. Это лучшие индикаторы вовлечённости на странице.

**Поведение и доступность — уже заложено, не потерять при переносе:**

- `prefers-reduced-motion` выключает все переходы.
- Фокус клавиатуры: обводка `2px #2F5AE6` с отступом 2px, видна всегда.
- Минимальная цель касания 44px — в футере, юридических ссылках, ставках угадайки, переключателях.
- Контраст: основной текст ≥4.5:1, заголовки ≥3:1. Проверено; при смене цветов пересчитать.
- Осмысленные `alt` на всех содержательных кадрах; пустой `alt` — только у подложек.
- Горизонтальной прокрутки нет нигде; `overflow-x:hidden` на `body`.

**Адаптив.** Заложен на `clamp()` и `auto-fit`, плюс медиазапросы:

| Порог | Что меняется |
|---|---|
| ≤1000px | Угадайка 4 колонки → 2 |
| ≤900px | Липкие колонки распрямляются (`[data-r="sticky"]`), поля секций 16px |
| ≤640px | Верхний отступ секций 88px |
| ≤480px | Трекинг H1 −.02em |

Отдельно проверить на телефоне: стопку шагов (липкость выключается — фреймы идут подряд), угадайку (две колонки, ставки не должны требовать зума), калькулятор (ползунки под палец), таблицу сравнения (наша колонка первой).

## 4. Страница статьи

Липкая шапка с полосой прогресса чтения, обложка 28px, колонка текста 680px, врезка-инфографика, цитата, тёмный блок с призывом, блок «поделиться» (Telegram, ВКонтакте, WhatsApp, копирование ссылки), подпись автора, липкое оглавление справа, три карточки «ещё в журнале», футер главной.

Тексты и цифры статьи — правдоподобная заглушка в нашей тональности. Перед публикацией заменить на свои и добавить `Article` в JSON-LD.

## 5. Чего в макете сознательно нет

- Логотипов клиентов и отзывов — пока нет согласий; пустая полоса с серыми плашками хуже её отсутствия.
- Календаря записи как основного действия — барьер для холодного трафика; основное действие форма из трёх полей.
- Обещаний процента снижения возвратов — позиция «мы не обещаем процент, мы ставим счётчик».
- Второго сценария входа для тех, кто не готов оставлять контакт (PDF, пример отчёта) — обсудить отдельно.
