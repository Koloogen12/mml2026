этого пока нет.** Никаких тостов, которые врут об успехе.

## 🟡 Разметка gold-set — была дыра в данных

**Проблема:** оператор оценивал **статичную демо-пару**, а `POST /labels` писал это в
**реальный** gold-set без привязки к сессии. То есть модель училась бы на выдумке.

✅ **Сделано по-настоящему:** `GET /admin/label-queue` — лента реальных пар
«запрос человека → ответ ИИ с товарами» из `chat_messages`, с догрузкой карточек
показанных товаров (оператор видит то, что оценивает). Оценка пишется с
`message_id` / `session_id` / `user_id`. Фильтр «Неразмеченные» — настоящий
(`NOT EXISTS` по `answer_labels`), после сохранения пара уходит из ленты.

Проверено: 14 реальных пар; оценка легла с `message_id=37` + привязкой к сессии;
пара исчезла из неразмеченных (14 → 13). No-op фильтры «По партнёру / По поводу /
Только 👎» убраны — их нечем было применять.
