# Онбординг + Паспорт стиля — спека экранов для Claude Design

**Что это:** структура страниц, флоу и UX онбординга и вкладки «Паспорт стиля». Токены, шрифты и компоненты НЕ описываю — они уже в системной инструкции проекта. Здесь только: порядок экранов, что на каждом, взаимодействия, состояния и какие данные собираем.

**Основано на:** [STYLE_PASSPORT_AND_RECS.md](./STYLE_PASSPORT_AND_RECS.md) (трёхслойная модель данных + методология стилистов), [PRD.md](./PRD.md) (экраны 4a–4d).

---

## Принципы онбординга (соблюдать во всех экранах)

1. **Lifestyle-first, не clothes-first.** Первым — «как выглядит твоя неделя», а не вопросы про вещи.
2. **Всё до регистрации, всё Skippable.** Собираем локально, auth — последним шагом, мёржим. На каждом шаге видимый «Пропустить».
3. **Прогресс виден.** Степпер сверху (N из M). Можно назад.
4. **Спрашиваем мало — с высоким сигналом.** Тяжёлое (замеры, фото) — опционально и позже.
5. **Финал — расшариваемый «паспорт-карта».** Онбординг вознаграждается идентити-картой, которой хочется поделиться.
6. **Обращение — на «вы», тон стилиста-консьержа.**

Каждый экран показать в состояниях: **дефолт · выбрано/заполнено · пусто · загрузка · ошибка · «Пропустить»** (где применимо).

## Карта флоу

```
Splash (O0) → Welcome (O1) → Value-карусель (O2)
   → [Онбординг паспорта]
        O3  Неделя / для кого        (lifestyle-first)
        O4  Эстетики стиля           (пресеты, выбор 1–3)
        O5  БРЕНДЫ (Spotify-style)   ← ключевой новый экран
        O6  Три слова / идентичность (парные поля)
        O7  Ограничения-дилбрейкеры
        O8  Размеры и бюджет
        O9  Фото для паспорта  → O9a Consent 152-ФЗ  (опционально)
   → O10 Транзишн «Собираем ваш паспорт…»
   → O11 Паспорт стиля — reveal (идентити-карта, шэринг)
   → O12 Регистрация (сохранить паспорт) — последний шаг
   → Home

Вкладка «Паспорт» (P1) в таб-баре — постоянный доступ к просмотру/редактированию.
```

## Экраны

### O0 · Splash · O1 · Welcome · O2 · Value-карусель
Уже покрыты дизайн-каноном (4a/4b). Напоминание: O2 — 5 слайдов живых мини-демо, **слайд №2 = примерка (До/После)** — наш дифференциатор. Постоянная CTA «Собрать паспорт стиля». В конце O2 — переход в O3.

---

### O3 · Неделя / для кого (lifestyle-first)
**Цель:** грубый lifestyle-pie + для кого подбираем. Собирает: `for_whom`, черновой `lifestyle_allocation`.
**Структура:**
- Заголовок: «Расскажите, как проходит ваша неделя».
- Блок 1 — «Для кого подбираем»: сегмент-переключатель (женское / мужское / без разницы).
- Блок 2 — **lifestyle-аллокатор**: 5–6 крупных карточек-поводов (Работа · Повседневное · Выходы/вечер · Спорт · Дом · События) с **простым способом задать долю** — не проценты, а «сколько времени»: 3-позиционный сегмент на каждой карточке (редко / иногда / часто) ИЛИ перетаскиваемые «доли пирога». Визуально — растущая заливка карточки.
- Подсказка внизу: «Это задаёт, чего в гардеробе должно быть больше».
**Взаимодействие:** тап по уровню на карточке; сумма нормализуется автоматически (не заставляем считать %).
**Состояния:** ничего не выбрано (CTA «Далее» неактивна до 1 выбора), выбрано, «Пропустить».

---

### O4 · Эстетики стиля (пресеты)
**Цель:** `style_persona_blend` (taste-вектор). Собирает выбор 1–3 эстетик.
**Структура:**
- Заголовок: «Какие образы вам ближе? Выберите 1–3».
- Сетка **фото-карточек 2-в-ряд**: каждая = имя эстетики + 2 слова описания (Минимализм — «чисто, ничего лишнего»; Old Money — «тихая роскошь»; Стритвир; Романтика; Классика; Спорт-шик; Бохо; Дерзкий/edgy…). Фото — плейсхолдеры.
- Выбор = рамка + чек в углу; счётчик «Выбрано 2 из 3».
**Взаимодействие:** мультивыбор до 3; при попытке 4-го — мягкая подсказка «до трёх».
**Состояния:** дефолт, 1–3 выбрано, лимит, «Пропустить».

---

### O5 · БРЕНДЫ — как Spotify / Apple Music ⭐ (ключевой экран)
**Цель:** `brands_love[]` (и опционально `brands_avoid[]`). Это самый вовлекающий экран — сделать «вкусно».
**Модель взаимодействия — «выбор любимого» как в музыкальном онбординге:**

**Структура:**
- Заголовок (крупно): «Какие бренды вы любите?» + подзаголовок «Выберите хотя бы 3 — соберём подборку под ваш вкус».
- **Поиск** сверху (sticky): поле «Найти бренд…» — по мере ввода фильтрует сетку.
- **Жанр-чипы** (горизонтальный скролл, sticky под поиском): фильтры-категории — Все · Масс-маркет · Премиум · Дизайнерские · Локальные (РФ) · Спорт · Обувь · Украшения. Тап переключает секцию сетки.
- **Сетка брендов** — карточки/кружки с логотипом бренда (плейсхолдер = монограмма бренда на плашке), имя под ним. Плотная сетка 3-в-ряд (или «пузыри» разного размера как Apple Music — по популярности).
- **Состояние выбора:** тап по карточке = заливка + галочка/«+→✓», лёгкий «поп»-масштаб (микроанимация как Apple Music). Повторный тап снимает.
- **Прогрессивное раскрытие (важная механика Spotify):** после выбора ~3 брендов внизу появляется **новая секция «Раз вам нравится … — вот похожие»** с подборкой рекомендованных брендов (расширяет выбор без ручного поиска).
- **Липкая нижняя CTA с динамическим счётчиком:** «Продолжить · выбрано 5». Неактивна до 3.
- Ссылка-текст внизу: «А что точно не носите?» → открывает быстрый под-шаг O5a.

**O5a · Анти-бренды (bottom sheet, опционально):** та же сетка/поиск, но выбор = `brands_avoid[]` (визуально иначе — приглушённо/зачёркнуто). Короткий, пропускаемый. Это ценный сигнал-исключение.

**Состояния O5:**
- Пусто (ничего не выбрано, CTA disabled, подсказка «Выберите хотя бы 3»).
- Идёт выбор (счётчик растёт, появилась секция «похожие»).
- Поиск: есть результаты / «Не нашли бренд? Добавьте вручную» (свободный ввод).
- Загрузка сетки (скелетон-плитки).

**Собирает:** `brands_love[]`, `brands_avoid[]`. Бонус: бренды — прокси бюджета и эстетики (обогащают паспорт даже без явного бюджета).

---

### O6 · Три слова / идентичность (парные поля)
**Цель:** парные `style_self_described` / `style_aspirational` + `desired_mood_default`; лёгко `body_love` / `body_downplay`. *Разрыв между парой = бриф на стайлинг.*
**Структура (механика «три слова» Bornstein — легко в чате):**
- Заголовок: «Опишите свой стиль тремя словами».
- Три поля-подсказки с пресет-чипами + свободный ввод:
  1. **Практическое** — «Что вы носите чаще всего?» (чипы: джинсы+свитер, костюм, платья…)
  2. **Аспирационное** — «Каким хотите, чтобы вас видели?» (утончённый, дерзкий, расслабленный…)
  3. **Эмоциональное** — «Как хотите себя чувствовать?» (уверенно / комфортно / энергично / статусно) → это `desired_mood_default`.
- Опциональный мини-блок «Фигура» (пропускаемый, деликатный): «Что любите подчеркнуть? / Что скрыть?» — чипы, без давления.
**Состояния:** пусто, частично, «Пропустить». Формулировки мягкие, не медицинские.

---

### O7 · Ограничения-дилбрейкеры
**Цель:** `hard_constraints` (фильтры-ИСКЛЮЧЕНИЯ, не веса).
**Структура:**
- Заголовок: «Что не показывать никогда?»
- Тумблеры/чипы: «Без каблука» (+ слайдер макс. высоты), «Только этичные бренды», «Без меха», «Без синтетики», «Скромный крой», «Без …» (свободное добавление).
- Подсказка: «Эти правила жёсткие — такие вещи просто не появятся».
**Состояния:** ничего (ок, пропускаемо), выбрано, «Готово».

---

### O8 · Размеры и бюджет
**Цель:** `size_by_category`, `budget_by_category`. Можно отложить (не блокировать).
**Структура:**
- Заголовок: «Размеры и бюджет — чтобы показывать только доступное вам».
- **Размеры плитками по категориям**: верх / низ / обувь (+ «уточнить позже»). Диапазон, не точные обхваты.
- **Бюджет по категориям слайдерами-диапазонами**: per-item тиры (верх, низ, обувь, верхняя, сумки). Не одна цифра.
- Крупный «Заполнить позже» — не терять пользователя.
**Состояния:** пусто/«позже», заполнено, частично.

---

### O9 · Фото для паспорта (опционально) → O9a Consent 152-ФЗ
**Цель:** вход для colorimetry (цвет кожи/волос/глаз, контраст) и опц. сезон/архетип. Строго опционально.
**Структура O9:**
- Заголовок: «Добавьте фото — подберём вашу палитру и точнее посадку».
- Выбор: сделать селфи / загрузить. Подсказка про свет («ровный дневной свет — точнее результат»).
- Кнопка «Пропустить — соберу паспорт без фото».
**O9a · Consent-gate 152-ФЗ (блокирующий bottom sheet ДО анализа):** тот же компонент, что S6a перед примеркой — 4 пункта (что берём / зачем / контроль / хранение в РФ), 2 непреселекченных чекбокса (обязательный + опциональный «хранить фото»), CTA неактивна до обязательного, версия+дата, ссылки на политику/БПД, ООО МОНОРУС.
**Рамка честности (обязательно в UI):** результат — «подсказка по вкусу», не диагноз; фото при плохом свете влияет на результат.
**Состояния:** нет фото (пропущено), фото выбрано, нет согласия (→ O9a), плохое качество (переснять), обработка.

---

### O10 · Транзишн «Собираем ваш паспорт…»
Экран-пауза (как «Personalizing…» у Daydream): короткая анимация + сменяющиеся подписи («Анализируем палитру…», «Подбираем под ваш вкус…»). 2–4 сек. Настраивает ожидание перед reveal.

---

### O11 · Паспорт стиля — REVEAL (идентити-карта, расшариваемая)
**Цель:** вознаградить онбординг красивой картой + дать шэринг (виральность).
**Структура (формат «identity-card», проверенный виральными промптами):**
- **Карта-паспорт** (крупная, скриншотопригодная):
  - (если было фото) портрет-плейсхолдер + палитра-свотчи + ярлык сезона;
  - **бленд эссенций** (напр. «Классика · Романтика») — как теги, не один ярлык;
  - топ-эстетики и 2–3 любимых бренда (логотипы);
  - строка настроения/«три слова».
- **Кнопки:** «Поделиться» (шэр-карта), «Начать подбор» (в чат), «Уточнить паспорт» (в редактирование).
- Тон рамки: «Это стартовая точка — паспорт уточняется с каждым выбором».
**Состояния:** полный паспорт / облегчённый (без фото — без палитры, но с эстетиками/брендами).

---

### O12 · Регистрация (последний шаг)
«Сохраните ваш паспорт»: телефон (SMS) / Apple / Google / VK. Локальный паспорт мёржится в аккаунт. Юр-строка. → Home.
**Состояния:** ввод номера → код → ошибка/таймер; соц-вход; «Продолжить как гость» (паспорт живёт локально, без сохранения между устройствами).

## Вкладка «Паспорт стиля» (P1) — просмотр и редактирование

Постоянный доступ из таб-бара (Чат · Коллекции · **Паспорт** · Профиль). Это ЛК-версия паспорта — всё редактируемо.

**Структура (сверху вниз):**
- **Хедер — идентити-карта** (как O11, компактнее) + «Поделиться».
- **Секции-строки, каждая раскрывается в редактор (bottom sheet):**
  1. **Цвет и палитра** — сезон + свотчи; «Пересобрать по фото».
  2. **Стиль** — бленд эссенций **слайдерами вкуса** (yin↔yang, спокойный↔яркий и т.п.) + топ-эстетики. Редактируемо — пользователь переопределяет ярлык (важно: типология = гипотеза, не истина).
  3. **Бренды** — кружки-логотипы (любимые) + «+ добавить» (открывает O5-подобный пикер); отдельно «не ношу».
  4. **Размеры** — плитки по категориям.
  5. **Бюджет** — слайдеры-диапазоны по категориям.
  6. **Образ жизни** — lifestyle-pie (редактируемый).
  7. **Правила** — `hard_constraints` (тумблеры/чипы).
  8. **Настроение по умолчанию** — чипы.
  9. **Согласия и биометрия (152-ФЗ)** — список выданных согласий (версия+дата), **«Удалить биометрические данные»**, экспорт.
- Внизу: «Чем полнее паспорт — тем точнее подбор» + прогресс-полоса заполненности.

**Состояния:** заполненные секции / пустые с призывом дозаполнить / редактирование (sheet) / сохранение (тост) / удаление данных (подтверждение).

| Экран | Данные (слой) |

| O3 Неделя | `for_whom`, `lifestyle_allocation` (SLOW) |
