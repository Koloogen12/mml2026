## 3. Схемы блоков

Обозначения: `▓` заполненная область, `░` изображение или видео, `───` линия, `[ ]` кнопка.

### Шапка
```
┌────────────────────────────────────────────────────────┐
│ ЗНАК                              [Показать на моих]   │  72px
└────────────────────────────────────────────────────────┘
   прозрачная поверх экрана 1 → при прокрутке фон + размытие
```

### 6. Почему это работает
```
┌──────────────────────────┬──────────────────────────────┐
│  ░░░░░░░░░░░░░░░░░░░░░░░░│░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │
│  ░   ГЕНЕРАТОР        ░░░║░░░        МЫ            ░░░  │  ← шторка
│  ░   один человек     ░░░║░░░   одна поза          ░░░  │
│  ░░░░░░░░░░░░░░░░░░░░░░░░│░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │
└──────────────────────────┴──────────────────────────────┘
        ║ = перетаскиваемый разделитель

┌───────────────┬──────────┬──────────┬═══════════┐
│               │Маркетплейс│Генератор │║ MakeMeLook║
│ Слоёв одежды  │   один   │  один    │║ до пяти  ║
│ Размер        │   нет    │  нет     │║ по сетке ║
│ Где работает  │ их площ. │ отдельно │║ ваш сайт ║
│ Чей товар     │ их каталог│похожая  │║ ваш арт. ║
└───────────────┴──────────┴──────────┴═══════════┘
      наша колонка: приподнятая поверхность + акцентная граница
      слова, не галочки
```
Телефон: таблица разбирается на три карточки-колонки, наша первой. Горизонтальной прокрутки нет.

## 6. Поведение на телефоне

Всё в одну колонку. Отличия от десктопа:

- Экран 1: текст, кнопки, затем видео не выше 60vh
- Блок 2: вертикальная стопка шагов, соединители сверху вниз
- Блок 3: сетка 2×4
- Блок 5: калькулятор первым, текст под ним
- Блок 6: таблица разбирается на три карточки-колонки, наша первой; горизонтальной прокрутки нет
- Блок 9: карточка «что нужно от команды» не прилипает, идёт после ленты
- Блоки 11 и 13: вопрос над ответом
- Липкая полоса с кнопкой появляется после экрана 1 и прячется у формы
