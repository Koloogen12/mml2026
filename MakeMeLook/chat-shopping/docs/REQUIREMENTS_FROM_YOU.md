## 1. Продуктовые решения

- 🔴 **Первый источник каталога** — с какого маркетплейса/сети берём товары первыми: Wildberries / Ozon / Lamoda / Yandex Market / прямые бренды. (Блокирует E1 — бэкбон.)
- 🔴 **CPA-сеть** — есть ли аккаунт в Admitad / ePN / другой? Каких рекламодателей уже одобрили? Есть ли прямые договорённости с брендами по комиссии? (Блокирует монетизацию E4.)
- 🔴 **iOS-стратегия** — начинаем с PWA и позже нативка? Обёртка Capacitor? Или нативное iOS сразу? (Влияет на структуру фронта и найм.)
- 🔴 **LLM-провайдер и бюджет** — на чём крутим оркестратор диалога: Gemini/OpenAI через прокси или локальные GigaChat/YandexGPT? Какой месячный бюджет на инференс закладываем?
- 🟡 **Финальное имя/бренд** — остаёмся «MakeMeLook» или отдельный бренд? (Нужно для домена, ассетов, юр-документов.)
- 🟡 **Кто разрабатывает** — ты соло / есть штат / нанимаем подрядчиков? Сколько людей и какие роли уже есть? (От этого зависит план и параллелизм.)
- 🟢 **Целевая аудитория по возрасту** — подтверждаем «вы» как обращение (сейчас так). Если ядро — Gen-Z, обсудим «ты».
- 🟢 **Приоритет гео** — только РФ на старте или сразу СНГ (влияет на валюты/локали)?

## 2. Доступы, аккаунты, ключи

- 🔴 **Google Gemini API** — ключ и квота (для примерки в масштабе + обогащения каталога). Тот же проект, что у виджета, или новый? Какой лимит?
- 🔴 **Каталог-фиды** — доступ к YML/XML/API первого источника: партнёрский фид сети ИЛИ seller-API маркетплейса. Ключи/URL.
- 🔴 **CPA-сеть API** — логин + API-ключи Admitad/ePN, список одобренных офферов, формат postback.
- 🟡 **SMS-провайдер** для авторизации по номеру — какой шлюз используем (или уже есть)? Ключи.
- 🟡 **Apple Developer account** — для Sign in with Apple, APNs (пуши) и будущего iOS-приложения. Есть ли?
- 🟡 **VK ID** — app_id + secret (вход через VK, актуально для РФ). Google OAuth client — для входа Google.
- 🟡 **Cloudflare** — доступ к аккаунту (там живёт `cf-worker-tg-proxy.js`, будем расширять как LLM-прокси).
- 🟡 **GigaChat / YandexGPT** — если используем как fallback: авторизация Сбер/Яндекс Cloud, ключи.
- 🟢 **Object storage** — используем текущий MinIO/бакет прод-сервера или заводим отдельный для новой платформы?
- 🟢 **Домен(ы)** — какой домен/поддомен под чат-платформу; доступ к DNS.
- 🟢 **Хостинг/деплой** — та же схема (systemd+nginx на 45.92.176.137) или отдельный сервер/облако под нагрузку примерки (GPU/очереди)?
- 🟢 **Push (web)** — сгенерируем VAPID-ключи сами, просто подтверди, что делаем web-push.

- 🟢 **Оферта для партнёров** (когда дойдём до B2B) — условия CPA-выплат.

## 4. Контент и данные

- 🔴 **Реальный каталог** — доступ к фиду с товарами (фото, цены, наличие, размеры, deeplink). Самый большой разблокировщик: без него всё на плейсхолдерах.
- 🟡 **Размерные сетки брендов** — если есть, повышают качество примерки и подбора размера.
- 🟢 **Стартовые пресеты стилей и бренды** для онбординга (4c) — список стилей + бренды под каждый (можем собрать сами, но твой вкус/приоритеты помогут).
- 🟢 **Есть ли текущая база пользователей / аналитика** с виджета, которую можно использовать для холодного старта рекомендаций? (Скорее всего нет — тогда стартуем на чистом retrieval, это ок.)
