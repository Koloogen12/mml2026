## 1. Обзор продукта

**MakeMeLook** -- B2B SaaS-платформа виртуальной примерки одежды на базе AI. Позволяет интернет-магазинам встраивать виджет виртуальной примерки на свой сайт. Покупатель загружает своё фото, выбирает одежду из каталога магазина и видит, как вещи будут выглядеть на нём -- в реальном времени, с учётом параметров тела.

### Ключевые метрики ценности
- **Для магазина:** рост конверсии в покупку, снижение возвратов, увеличение среднего чека, сбор лидов
- **Для покупателя:** возможность "примерить" одежду онлайн без посещения магазина, уверенность в выборе размера

### Технологический стек
- **Backend:** Go (Chi router, GORM, PostgreSQL, Minio S3)
- **Admin Panel:** React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui
- **Widget:** React (IIFE bundle, встраивается одной строкой кода)
- **AI Engine:** Google Gemini (Nano Banana Pro) через CometAPI

## 2. Типы пользователей

### 2.1 Владелец магазина (Merchant / Store Owner)

**Кто:** владелец или менеджер интернет-магазина одежды
**Цель:** увеличить конверсию и снизить возвраты через виртуальную примерку
**Как взаимодействует:** через админ-панель (SaaS-кабинет)

### 2.2 Покупатель (Lead / End User)

**Кто:** посетитель интернет-магазина
**Цель:** понять, как одежда будет выглядеть на нём, перед покупкой
**Как взаимодействует:** через виджет, встроенный на сайте магазина

### 2.3 Администратор платформы (внутренний)

**Кто:** команда MakeMeLook
**Цель:** управление платформой, мониторинг, поддержка
**Как взаимодействует:** через БД, логи, серверную инфраструктуру (нет отдельного admin UI)

## 3. User Flow: Владелец магазина

### 3.1 Регистрация и онбординг

```
Регистрация (email + пароль)
    |
Верификация email (6-значный код)
    |
Создание проекта
    |- Название магазина
    |- URL сайта
    |- Категория (одежда / обувь / аксессуары / мульти)
    |- Целевая аудитория
    |- Логотип (опционально)
    |
Онбординг-чеклист (4 шага):
    [x] Проект создан
    [ ] Виджет настроен
    [ ] Загружено >= 5 товаров
    [ ] Код установлен на сайт
```

### 3.2 Управление каталогом товаров

**3 способа загрузки:**

| Способ | Описание | Когда использовать |
|--------|----------|-------------------|
| Ручной | Форма с полями + загрузка фото | 1-50 товаров |
| CSV-импорт | Загрузка файла, маппинг колонок, валидация | 50-5000 товаров |
| Интеграция API | Автосинхронизация с CMS магазина | Постоянное обновление |

**Поля товара:**
- Название, SKU, категория, подкатегория
- Пол: женский, мужской, детский, унисекс
- Цена, цена со скидкой, валюта (RUB, USD, EUR, GBP, CNY)
- Размеры (XS-XXL), цвет, материал, бренд, сезон
- До 5 фотографий на товар
- Ссылка на товар в магазине
- Описание

**Категории товаров:**
- Верхняя одежда (outerwear)
- Топы и блузки (tops)
- Юбки и брюки (bottoms)
- Платья (dresses)
- Обувь (shoes)
- Аксессуары (accessories)
- Нижнее бельё (underwear)
- Спортивная одежда (sportswear)

**Управление:**
- Поиск, фильтрация по категории/полу/статусу/группе
- Bulk-операции: активация, деактивация, удаление, добавление в группу
- Группы товаров для организации каталога
- Дубликаты определяются по SKU при импорте

| Платформа | Статус | Возможности |

4. Запуск синхронизации

### 3.4 Настройка виджета

**Конфигуратор с live-превью и auto-save:**

| Вкладка | Настройки |
|---------|-----------|
| Кнопка | Позиция (4 угла), размер, цвет, анимация (pulse/bounce/none), тултип-текст |

| Элементы | Избранное, корзина, история примерок, powered by |

**Пресеты:** готовые стилевые шаблоны для быстрой настройки

### 3.7 Аналитика

**KPI-карточки (с трендами vs предыдущий период):**
- Просмотры виджета
- Открытия виджета
- Количество примерок
- Уникальные пользователи
- Конверсия в корзину
- Добавления в корзину
- Выручка
- Средний чек

**Воронка конверсии:**
```
Показ виджета → Открытие → Заполнение параметров → Загрузка фото →
Первая примерка → Повторная примерка → Добавление в избранное → Корзина
```
С подсветкой этапа максимальной потери.

**Тренды:** графики по метрикам с выбором периода (1д / 7д / 30д / 90д)

**Топ товаров:** рейтинг по примеркам, избранному, добавлениям в корзину

**Аудитория:** распределение по полу, размерам, типам фигур, устройствам

- Список лидов с фильтрацией (email, пол, период)
- Детальная карточка лида: параметры тела, фото, история примерок, корзина
- Экспорт в CSV

### 3.9 Профиль и безопасность

- Редактирование профиля (имя, телефон, компания, сайт, страна, часовой пояс)
- Загрузка аватара

## 4. User Flow: Покупатель (виджет)

### 4.1 Онбординг (линейный, этапы опциональны)

```
Интро (приветствие)
    |
Выбор пола (женский / мужской)
    |
Основные параметры (рост, вес)
    |
Обмеры (грудь, талия, бёдра)
    |
Форма живота (выбор из вариантов)
    |
Тип фигуры (груша, песочные часы, прямоугольник и др.)
    |
Политика конфиденциальности (обязательно)
    |
Загрузка фото (собственное фото или выбор аватара)
```

Каждый этап (кроме политики конфиденциальности) может быть отключён владельцем магазина. Прогресс сохраняется в localStorage между визитами.

### 4.2 Рекомендации по фото

Отдельный экран с примерами хороших и плохих фото:
- Полный рост, лицо видно
- Однотонный фон
- Без верхней одежды
- Хорошее освещение

### 4.3 Шоурум (основной экран)

**Левая панель:** 5 слотов слоёв одежды (outerwear, tops, bottoms, shoes, accessories)
- Пустые слоты показывают "+" и название категории
- Заполненные слоты показывают превью товара с бейджем размера
- Свайп вверх по слоту -- снятие вещи

**Правая панель:** кнопки действий
- Меню (три точки)
- Полноэкранный режим
- Добавить в избранное
- Поделиться результатом

**Нижняя панель:**
- Кнопка текущей категории/подкатегории (чёрная, 180px, border-radius: 7px)
- По клику -- попап со списком всех подкатегорий и количеством товаров
- Горизонтальная карусель карточек товаров
- Кнопки "Примерить" и "Снять"

### 4.4 Процесс примерки

```
Покупатель выбирает до 5 вещей (по одной на категорию)
    |
Нажимает "Примерить"
    |
Показывается лоадер (с кнопкой "Закрыть" поверх)
    |
Backend отправляет запрос в Gemini API:
    - Фото покупателя (или аватар)
    - Фото выбранных товаров (до 5)
    - Промпт с параметрами тела и метаданными товаров
    |
Результат: фотореалистичное изображение покупателя в выбранной одежде
    |
Покупатель может:
    - Сохранить в избранное
    - Добавить товары в корзину
    - Поделиться результатом
    - Скачать изображение
    - Попробовать другие вещи
```

### 4.5 AI-примерка: детали промпта

Промпт учитывает:
- **Материал вещи:** замша, кожа, деним, шерсть, хлопок, шёлк, синтетика -- каждый с уникальными правилами драпировки
- **Силуэт:** бомбер, оверсайз, слим, широкие брюки, укороченный и др.
- **Параметры тела:** рост, вес, обхваты -- влияют на степень облегания
- **Layering:** правильный порядок слоёв (топ под верхней одеждой, обувь на ногах)
- **Preservation rules:** лицо, тело, фон, освещение, анатомия -- 100% сохранение оригинала

### 4.6 Корзина и избранное

- **Избранное:** сохранение результатов примерок и товаров
- **Корзина:** добавление товаров, переход к оформлению заказа на сайте магазина
- **История примерок:** все предыдущие результаты с возможностью просмотра

### 4.7 Аутентификация покупателя

| Способ | Описание |
|--------|----------|
| OTP по email | 6-значный код, TTL 10 мин, cooldown 60 сек |
| Google OAuth | Popup-окно, redirect через наш бэкенд |
| Яндекс OAuth | Popup-окно, redirect через наш бэкенд |

Аутентификация опциональна -- покупатель может использовать виджет без регистрации.

### 4.8 Шеринг результатов

- **Watermark:** логотип MakeMeLook на каждом результате примерки (полупрозрачный, правый нижний угол)
- **Share-страница:** брендированная HTML-страница с OG-тегами
  - Превью в Telegram, VK, WhatsApp
  - Изображение результата
  - Список вещей в образе
  - CTA "Попробовать тоже" -> сайт магазина
- **Каналы:** копирование ссылки, Instagram, Telegram, VK
- **Скачивание:** сохранение результата как JPG

### 4.9 Настройки (внутри виджета)

- Изменение параметров тела
- Загрузка нового фото
- Просмотр избранного
- Управление аккаунтом
- Политика конфиденциальности

## 6. Безопасность

- **Верификация домена:** виджет загружается только на разрешённых доменах
- **Rate limiting:**
  - Widget API: лимит запросов по IP в минуту
  - Try-on: 20 запросов/час/IP + 50 запросов/сессия
- **JWT-аутентификация** для SaaS-кабинета (access + refresh токены)
- **OAuth 2.0** для покупателей (Google, Яндекс)
- **CORS:** настраиваемые allowed origins
- **Soft delete:** данные не удаляются физически (GDPR)
- **Хеширование паролей**

## 8. Инфраструктура

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Backend | Go, systemd | API, бизнес-логика |
| Frontend | React, Nginx | SaaS-кабинет |
| Widget | React IIFE bundle, CDN | Встраиваемый виджет |

| AI | Google Gemini via CometAPI | Генерация изображений |

**Деплой:**
- Backend: `go build` + systemd service на VPS
- Frontend: `npm run build` + Nginx static serving
- Widget: `npm run build` + CDN
- Nginx reverse proxy для API, S3, статики

## 9. Текущие ограничения и известные gaps

| Область | Описание | Приоритет |
|---------|----------|-----------|
| SMS-верификация | Только логирование кода, нет интеграции с SMS-провайдером | Средний |
| Email-рассылки | Нет приветственных писем, нет email-маркетинга | Средний |
| Биллинг | Нет системы оплаты и тарифных планов | Высокий |
| Revenue tracking | Нет реального отслеживания выручки (нет webhook от магазина) | Средний |
| Mobile app | Нет мобильного приложения | Низкий |
| A/B тестирование | Нет встроенного A/B-тестирования виджета | Низкий |
| Multi-tenant isolation | Все данные в одной БД | Низкий |

## 10. Точки для анализа CPO

### Рекомендуемые направления исследования:

1. **Воронка онбординга мерчанта:** где отваливаются? Сколько доходят до установки виджета?
2. **Воронка покупателя:** какой этап виджета имеет максимальный drop-off?
3. **Unit-economics:** стоимость одной примерки (Gemini API) vs ценность для магазина
4. **Retention:** как часто покупатели возвращаются к виджету?
5. **Ценообразование:** какая модель подписки оптимальна?
6. **Конверсия шеринга:** сколько людей переходят по share-ссылкам?
7. **Качество AI:** удовлетворённость результатами примерки
8. **Расширение категорий:** ювелирные украшения, оптика, макияж?
9. **Интеграции:** Shopify, WooCommerce, Tilda -- расширение охвата
10. **Мультимодальность:** видео-примерка, 360-просмотр?
