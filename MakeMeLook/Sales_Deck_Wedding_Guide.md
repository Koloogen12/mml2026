# Sales Deck: MakeMeLook для свадебных салонов

## СЛАЙД 1 — Титульный (Hero)

### БЫЛО:
- Заголовок: «Виртуальная примерочная, для онлайн-покупателей без очередей»
- Метрики: –25% / +40% / +35%
- Изображение: телефон с повседневной одеждой

### СТАЛО:

**Подзаголовок (мелкий, сверху):** MakeMeLook

**Заголовок (крупный):**
```
Виртуальная примерка
свадебных платьев —
невеста выбирает до визита
```

**3 метрики (в карточках внизу):**

| Метрика | Значение | Подпись |
|---------|----------|---------|
| Левая   | –80%     | Нецелевых визитов |
| Центральная | +40% | Конверсия из визита в покупку |
| Правая  | ×3       | Скорость выбора платья |

**Изображение справа:** Мокап телефона, на экране — невеста в свадебном платье в нашем виджете. Слева от телефона — миниатюры разных свадебных платьев (A-line, русалка, пышное).

**Комментарий:** Метрика «–80% нецелевых визитов» — ключевой hook. Салоны поймут мгновенно. Это их #1 боль.

## СЛАЙД 2 — Проблема (Боль салона)

### БЫЛО:
- «Легкий старт / Инструмент для решения проблем»
- Чекбоксы: больше покупок, точный подбор размера, персонализированный шопинг, рост CR

### СТАЛО:

**Подзаголовок (синий, мелкий):** Проблема

**Заголовок (крупный):**
```
Роспотребнадзор запретил
платные примерки.
А нецелевые клиенты остались.
```

**4 блока с иконками (✕ вместо ✓, красные/тревожные):**

```
✕  Примерка = 1 час времени консультанта. Из 5 визитов покупает одна
✕  Каждая примерка — износ платья за 50 000–300 000 ₽
✕  С 28 марта 2026 брать плату за примерку — нарушение закона (штраф до 500K ₽)
✕  Невесты обходят 5–10 салонов «просто посмотреть» и не возвращаются
```

**Изображение справа:** Ноутбук с открытой статьёй «Роспотребнадзор запретил…» или скриншот новости. Альтернатива: фото переполненного свадебного салона.

**Комментарий:** Этот слайд — эмоциональный удар. Владелец салона должен подумать «блин, это прямо про нас». Конкретные цифры штрафов добавляют urgency.

## СЛАЙД 3 — Решение (Как мы решаем)

### БЫЛО:
- «Персональный стилист для каждого клиента»
- 4 чекбокса про стильные рекомендации

### СТАЛО:

**Подзаголовок (синий, мелкий):** Решение

**Заголовок (крупный):**
```
Невеста примеряет
20 платьев за 10 минут —
до визита в салон
```

**4 блока с иконками (✓ синие):**

```
✓  Невеста загружает фото и видит себя в каждом платье из вашего каталога
✓  Приходит в салон с 2–3 фаворитами — примерка за 30 минут вместо 2 часов
✓  Платья не изнашиваются от «просто посмотреть» — примерка только финалистов
✓  Собираем контакты невест — вы получаете базу тёплых лидов
```

**Изображение справа:** 2 экрана телефона: один с виджетом, где невеста в свадебном платье, второй с каталогом свадебных платьев.

**Комментарий:** Акцент на ПРЕДВАРИТЕЛЬНЫЙ ФИЛЬТР. Не заменяем живую примерку — мы делаем так, чтобы в салон пришла невеста, которая уже знает, что хочет.

## СЛАЙД 4 — Как это работает (User Flow)

### БЫЛО:
- «Что увидят клиенты» → 3 шага: запускают виджет → фото + параметры → личный стилист

### СТАЛО:

**Подзаголовок (синий, по центру):** Как это работает

**3 шага (3 мокапа телефонов):**

```
01                          02                          03
Невеста заходит             Загружает фото              Примеряет платья
на ваш сайт                 и указывает параметры       из вашего каталога
```

**Телефон 1:** Экран виджета с кнопкой «Начать ✨» и текстом:
```
Виртуальная примерка
Загрузите фото и примерьте свадебные
платья из нашего каталога за 1 минуту.
```

**Телефон 2:** Экран загрузки фото невесты (аналог текущего, но фото девушки в лёгком нарядe, не в верхней одежде)

**Телефон 3:** Шоурум — невеста в свадебном платье, слева миниатюры разных платьев (A-line, русалка, бальное, прямое), внизу карусель карточек.

**Комментарий:** Структура 1-в-1 с текущим слайдом. Меняем только контент скриншотов и подписи.
