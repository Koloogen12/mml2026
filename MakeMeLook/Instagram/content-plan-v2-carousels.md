## 0. Грамматика креатива (свод — применяется к каждому слайду)

1. **Одна продуктовая мысль на кадр**, поставленная физически: контрастом (резкость/blur), светом, масштабом. Не «красивое фото + подпись», а мысль, сыгранная в сцене.
2. **Контраст — носитель смысла.** Резкое = решение/продукт/она. Размытое = поток, каталог, сомнение, рынок.
3. **Один насыщенный цвет на кадр — кобальт/электрик.** Только там, где AI/примерка/решение. Всё остальное приглушено (ivory, серый, ink).
4. **Типографика — часть композиции.** Крупный serif ложится в размытые зоны, не трогает героиню. Мелкие служебные строки по углам (как тираж на постере): `MakeMeLook — AI-примерка`, номер слайда `01 / 04`.
5. **Тон:** консьерж. Без эмодзи, без восклицаний, на «вы».

**Производственный стек:**
- `nano_banana_2` (nb2) — кадры с русской типографикой прямо в изображении (проверено: рендерит кириллицу чисто) и текстовые слайды.
- `gpt_image_2` (gpt2) — чистые фотобазы без текста (кириллицу ему не давать) → апскейл до 2k (рендерит 880px, минимум ленты 1080).
- **Реальные генерации из прод-виджета** — для всего, что заявляет качество (П2, П6-С3, хайлайт «Примерка»). Здесь AI-стилизация запрещена: доказательство должно быть настоящим.
- Figma — UI-карточки, таблица сравнения, метрики, обложки хайлайтов (по бренд-киту).

## 2. Сетка и закреп

Порядок публикации П1→П6, в ленте сложится:
```
[ П6 ] [ П5 ] [ П4 ]   ← новый ряд: отстройка · как работает · B2B-оффер
[ П3 ] [ П2 ] [ П1 ]   ← базовый ряд: платформа · доказательство · манифест
```
Ритм обложек (слайд 1 каждого поста): светлый · светлый · тёмный / градиент · светлый · тёмный — Ink-плитки (П4, П6) не слипаются.

**Закреп:** Instagram даёт закрепить максимум **3** поста. Рекомендация: **П1 (манифест) + П2 (доказательство) + П4 (B2B-оффер)** — зашедший за 3 секунды получает «что это → это правда работает → что мне с этим делать». П4 в закрепе критичен: холодный мерчант из аутрича не должен листать до оффера.
