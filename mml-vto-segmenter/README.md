# mml-vto-segmenter

Сервис возвращает покупателю его собственное лицо после генеративной примерки.

## Зачем

Генеративная модель перерисовывает кадр целиком: лицо, волосы, кисти рук, фон.
Позиционирование продукта стоит на «не на модели, похожей на него, а на нём» —
значит перерисованное лицо это не косметический дефект, а удар в основание.

Маска через API задачу не решает: замерено, что при нескольких `image[]` в
`/v1/images/edits` она перестаёт влиять на результат. Поэтому личность
возвращаем на своей стороне — собираем итог из двух источников по семантической
сегментации.

## Как

Одна модель human parsing (MediaPipe multiclass selfie segmentation, 6 классов)
считает карту классов отдельно для оригинала и для генерации. Дальше таблица
`SRC_TABLE` в [regions.py](regions.py) для каждой пары (класс в оригинале ×
класс в генерации) говорит, откуда брать пиксель.

Таблица намеренно **несимметричная**:

* строка `CLOTHES` — всегда генерация. Старая одежда покупателя не вернётся ни
  при какой ошибке сегментации;
* столбец `CLOTHES` — генерация. Новая вещь имеет право вылезти за прежний
  силуэт: оверсайз, шапка поверх волос, рукав поверх предплечья;
* `FACE × CLOTHES` — единственное исключение, и оно **частичное**. Оригинал
  побеждает только внутри **ядра лица** (эллипс по глазам, носу и рту). По
  подбородку, челюсти и шее выигрывает одежда — иначе водолазка под горло, шарф,
  капюшон и воротник-стойка стирались бы с подбородка, а это половина осенней
  коллекции, а не редкий край.

**Ландмарок нет** (детектор не нашёл лица) — весь класс `FACE` отходит
оригиналу. Теряем воротник на паре процентов снимков, зато никогда не теряем
лицо. Цена несопоставима.

Побочный эффект правила совпадения классов: кисти рук опознают себя сами. Пиксель
«кожа в оригинале × кожа в генерации» приходит из оригинала без отдельного
детектора рук.

## Гейт

Две разные природы, [ci_gate.py](ci_gate.py):

**Уровень 1 — детерминированный, на всех фикстурах.** Утверждения без порогов:
пиксели с насыщенной маской побитово равны своему источнику; при отсутствии
ландмарок ни один пиксель `FACE` не ушёл в генерацию; маска соответствует
таблице. Ловит перепутанный порядок каналов, лишний ресемплинг, съехавший
композит — и работает там, где лицо закрыто козырьком или отвёрнуто.

**Уровень 2 — статистический, только на кадрах с найденным лицом.** Косинус
ArcFace против записанного эталона, просадка больше 0.02 роняет сборку.
ArcFace на закрытом лице неустойчив, поэтому мерить им закрытые лица
бессмысленно — их держит уровень 1.

Фикстура — пара готовых файлов (фото покупателя + **сохранённая** генерация).
Генерации не перезапрашиваются: гейт обязан падать от изменения нашего кода, а
не от настроения модели, и не должен стоить денег.

## Контракт с бэкендом

`POST /composite`, multipart `original` + `generated` → PNG.
Заголовки ответа: `X-Face-Found`, `X-Kept-Pct`, `X-Latency-Ms`, `X-Invariant-Ok`.

Сервис **обязан быть необязательным**: любая ошибка — 500, бэкенд по ней отдаёт
генерацию как есть и пишет в лог. Примерка не падает никогда.
