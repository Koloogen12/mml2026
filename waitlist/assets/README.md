# Ассеты waitlist-страницы

Страница работает и без картинок (градиентный hero + CSS-заглушки), но для финального вида нужно положить сюда:

| Файл | Что это | Размер |
|---|---|---|
| `waitlist-hero.png` | Полноэкранная fashion-картинка (фон справа) | ≥ 2000×1400, оптимизировать (<400 КБ, webp/avif лучше) |
| `fig/prod-blue-dress.png` | Товар в демо-чате — платье | ~200×260 |
| `fig/prod-cape.png` | Товар — пальто-кокон | ~200×260 |
| `fig/prod-sandals.png` | Товар — босоножки | ~200×260 |

Источник — Figma-файл `DD.fig` (в Downloads/Daydream). Экспортировать в PNG/WebP и положить сюда с этими именами. Как только `waitlist-hero.png` появится — hero подхватит его автоматически (JS проверяет наличие).
