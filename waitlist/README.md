# Waitlist — главная страница makemelook.ai

Standalone-страница листа ожидания (без рантайма Claude Design). Один `index.html`,
внешних зависимостей нет кроме Google Fonts. Собрана из дизайн-хендоффа `Waitlist.dc.html`.

## Что делает
- Hero + карточка листа ожидания: телефон (+ код страны) → «Продолжить» → модал «вы в списке» с номером очереди.
- Анимированное демо-чат справа (декоративное, vanilla JS, уважает `prefers-reduced-motion`).
- OAuth-кнопки Apple / Яндекс ID — пока заглушки (появятся с реальной auth).
- Деградирует без картинок: hero = градиент, карточки товара = плейсхолдеры.

## Перед деплоем — заполнить `CONFIG` в `<script>`:
- `WAITLIST_ENDPOINT` — POST `{phone}` (пусто = показываем успех без сохранения).
- `TELEGRAM_URL`, `TERMS_URL`, `PRIVACY_URL`, `PARTNERS_URL` — реальные ссылки.
- `BASE_QUEUE` — стартовый счётчик очереди.

## Ассеты
Положить в `assets/` (см. `assets/README.md`): `waitlist-hero.png`, `fig/prod-*.png`. Экспорт из `DD.fig`.

## Деплой
Статический `index.html` + `assets/` → в docroot того, что отдаёт корень makemelook.ai.
Точный путь зависит от текущего хостинга (уточняется). НЕ катить, пока не подтверждён путь и не заполнен `CONFIG`.
